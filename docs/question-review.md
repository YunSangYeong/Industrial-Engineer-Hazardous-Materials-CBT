# 문항 작성·내부 검토 기록

## 실제 집계 — 1,000개

| 과목 | 개념형 | 계산 조건 변형 | 계산 문맥 family | 내부 검토 후 등록 |
| --- | ---: | ---: | ---: | ---: |
| 일반화학 | 60 | 290 | 16 | 350 |
| 화재예방과 소화방법 | 55 | 270 | 15 | 325 |
| 위험물의 성질과 취급 | 55 | 270 | 15 | 325 |
| 합계 | 170 | 830 | 46 | 1,000 |

목표 1,000개 중 실제 기본 JSON 등록·내부 검토 문항 **1,000개, 부족 0개**. 원문 기출 0, 복원 0, 자체 제작 1,000. 기본 은행의 검증 대기 0. 개인의 로컬 등록분은 집계하지 않는다.

기존 120개를 보존하고 개념형 80개, 계산 40개 문맥×20개 조건=800개를 추가했다. 원래 계산 6개 문맥×5개 조건=30개와 합쳐 계산 변형 830개이다. **계산 문맥은 핵심 산식을 공유할 수 있다. 46개 family를 46개 독립 수학 개념이라고 세지 않으며 1,000개 독립 개념·기출을 확보했다는 뜻도 아니다.** 숫자만 다른 문항은 family로 묶는다. 개념형에도 서로 인접한 주제와 같은 원리의 다른 적용 상황이 있어 공식 출제 단원 수로 환산하지 않는다.

## 작성 근거와 권리

모든 문항은 AI의 일반 화학·연소·물질 취급 지식과 문제에 명시한 모형 조건으로 새로 작성했다. 외부 교재·민간 기출 사이트·시험지의 문구를 복제하지 않았다. 읽지 않은 공식 출제기준이나 교재를 정답 증빙으로 인용하지 않는다. 작성 기록 URL은 외부 정답 증빙이 아니다. 연도와 회차는 전부 null이며 원문 기출·복원으로 표시하지 않는다.

- 기본 개념 원고: `scripts/concepts.tsv` (90개)
- 추가 개념 원고: `scripts/concepts-expanded.tsv` (80개)
- 기존 계산 생성: `scripts/generate_bank.py` (30개)
- 추가 계산 조건·식·해설: `scripts/expanded_calculations.py` (800개)
- 실제 데이터: `src/data/questions.json`
- 실제 수·과목·문맥별 집계: `src/data/bank-summary.json`

자체 작성물의 적용 가능한 권리는 CC BY 4.0으로 제공한다. 표시: hazardous-materials-cbt contributors, 이 저장소 링크, 수정 여부. 앱 코드의 원본 MIT 고지는 LICENSE에 보존했다. 사용자 가져오기는 해당 사용자가 출처·권리를 확인하며 공용 은행에 자동 게시되지 않는다.

## 수행한 검토와 한계

- 개념형 170개: 각 문제의 조건, 네 보기의 정답 단일성, 해설의 논리·범위, 과도한 안전 단정 여부를 원고 수준에서 내부 검토했다. 추가 범위는 물질 분류·상변화·분자 극성·용액/평형/양론, 연소 형태·급격한 화재 전이·약제/설비의 한계, 주요 용매/분말/산화성 물질·제품 상태·저장/시료/자료 관리이다. 동일 AI 작업의 자기 검토이며 독립 전문가 검토가 아니다.
- 계산형 830개: Python Decimal 생성과 별도 TypeScript 산식으로 조건·수치·단위·정답 번호·반올림·동치 보기를 검사한다. 새 산술은 농도·희석·기체/분압·양론/가중 평균, 열수지/전달/유량/포 팽창, 밀도/형상/팽창/물질수지/농도 환산이다. 반올림은 양수 기준 소수 넷째 자리에서 반올림하여 셋째 자리까지이며, 정확히 나누어지지 않는 증발 농도에도 적용한다.
- 법적 지정수량·시설 기준·노출 한계·실제 제품 약제 혼합 지침·안전거리 판정값은 새로 만들지 않았다. 계산 문제의 물성·용해도·발열량·계수는 명시한 가상 조건이며 특정 제품에 대해 확인한 공식 물성으로 표시하지 않는다.
- ID와 NFKC/공백 정규화 본문·정렬된 보기 fingerprint로 전체 중복을 검사하고 각 family의 입력 조건을 비교한다. 원고와 계산 문맥을 검토해 같은 의미를 문구만 바꾼 복제는 추가하지 않았으며, 수치 변형과 공통 산식의 문맥별 재사용은 위 수량에 공개했다. 자동 fingerprint 자체가 의미 중복 완전 판정기는 아니다.
- 기존 120개는 내용·보기 순서·정답·해설·ID·출처까지 보존한다. 생성 시 SHA-256 고정값과 별도 단위 검사로 확인하므로 기존 풀이 기록 참조를 유지한다.
- 원문 기출의 재배포 허가·공식 회차는 확보하지 못했다. 공식 Q-Net 원문 접근 차단 상태를 재시도한 것으로 꾸미지 않는다. 공식 출제기준 전체 대조와 외부 전문가 검수는 미완료이며 최신 법령 전 범위를 포괄하는 문제은행은 아니다.
- `reviewed`는 이 범위의 **내부 검토 후 학습 사용** 상태이다. 공식 인증·전문가 검수 완료를 뜻하지 않는다. 별도 검증 대기 자료가 있으면 학습에서 제외한다.

## 재생성과 시험 추출

`python3 scripts/generate_bank.py`는 고정 원고·시드 2121001·조건·ID·정렬로 같은 은행과 양식을 생성한다. `npm test`는 은행·집계 JSON과 양식 2개의 바이트 단위 재생성을 검사한다. 기본 120개 전체의 보존도 별도로 확인한다.

시험은 과목별 20개를 추출하며 family당 우선 한 문제만 뽑는다. 개념형은 자체 ID당 한 슬롯, 계산형은 family당 한 슬롯을 사용하므로 20개 숫자 변형이 20개 독립 주제처럼 과다 추출되지 않는다. 현재 과목별 후보 슬롯은 76/70/70개로 한 회 20개보다 많아 같은 family 보충은 필요 없다. 사용자 은행에서 슬롯이 부족한 경우에만 나머지 고유 ID로 보충한다.
