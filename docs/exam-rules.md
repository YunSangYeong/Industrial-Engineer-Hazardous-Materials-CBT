2026-10-25 Q-Net 자격 상세 주소에 읽기 요청:
https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=2121

결과: `curl: (56) CONNECT tunnel failed, response 403`. 프록시에서 거부되어 원문·첨부 출제기준과 이용 조건을 읽지 못했다. URL은 확인 시도 대상이며 내용 열람 성공이나 해당 종목의 현재 기준 검증 증거가 아니다. 별도 공식 자료를 읽은 것으로 표시하지 않는다.

## 현재 앱의 명시적인 학습용 가정

`src/qualification.ts`에 다음 설정을 모았다. 일반 지식을 바탕으로 한 잠정 설정으로, 사용 전 최신 Q-Net 공식 자료와 대조가 필요하다.

- 대상: 위험물산업기사 필기, 발급/시행 기관으로 알려진 한국산업인력공단 Q-Net의 자격정보 확인 대기.
- 과목: 일반화학 / 화재예방과 소화방법 / 위험물의 성질과 취급.
- 객관식 4지선다, 각 과목 20개, 총 60개, 90분.
- 과목별 만점 100점, 동일 가중 평균 60점 이상이며 각 과목 40점 이상일 때 학습용 합격 표시.
- 한 과목의 정답당 5점, 전체 평균에는 100/60점 기여. 미응답은 오답. 합격은 표시 반올림 전 비율로 판정한다.
- 36개 정답이라도 한 과목 정답이 7개 이하이면 과락. 경계 8/20은 40점으로 과락 아님.
- 임의 추출 순서·난이도·단원 비율은 학습용이다. 공식 CBT의 실제 문항·분포를 재현했다는 증거가 없다.

## 이용 조건

Q-Net 또는 다른 웹사이트를 볼 수 있다는 것만으로 기출 재배포를 허용받았다고 보지 않는다. 공식 원문과 명확한 이용허락을 확보하지 않아 원문 기출·복원문제는 0개다. 현재 자체 제작 문제의 권리와 검토 범위는 [문항 검토 기록](question-review.md)에 공개한다. 시험 규칙·법령은 정기적으로 공식 원문과 대조해야 하며 이번 작업에서는 그 확인이 완료되지 않았다.
